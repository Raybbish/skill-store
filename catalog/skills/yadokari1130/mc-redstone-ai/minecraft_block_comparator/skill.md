# レッドストーンコンパレーターの詳細仕様

## Block ID
- `minecraft:comparator`

## プロパティ (Block States)
- `facing`: `north`, `south`, `east`, `west`
  - **【重要】向きの仕様 (Minecraft準拠)**: `facing` は **「入力側（背面）」** を向いている方角を指します。
  - **出力側**: `facing` で指定した方向の **真反対** へ信号を出力します。
  - **具体例**:
    - `facing: "north"` の場合：**北から主入力**を受け取り、**南へ出力**します。
    - `facing: "east"` の場合：**東から主入力**を受け取り、**西へ出力**します。
    - `facing: "south"` の場合：**南から主入力**を受け取り、**北へ出力**します。
    - `facing: "west"` の場合：**西から主入力**を受け取り、**東へ出力**します。
- `mode`: `compare` (比較モード), `subtract` (減算モード)
- `powered`: `true`, `false` (出力があるかどうか)

## 配置ガイドライン
- **`connects` の完全義務化**: **コンパレーターを配置する際は、いかなる場合でも必ず `connects` を使用してください。直接 `blocks` にコンパレーターを配置し、手動で `facing` プロパティを指定することは完全に禁止されています。**
- **配置時の `src` と `dst` の指定方法**:
  - `src`: 信号の背面主入力元となるブロックの座標（コンパレーターの背面）を指定します。
  - `dst`: 信号の出力先となるブロックの座標（コンパレーターの前面）を指定します。
  - `component`: `"minecraft:comparator"`
  - **具体例**: `[10, 65, 10]`（入力元）から `[12, 65, 10]`（出力先）に向けてコンパレーターを配置する場合、`connects` は以下のようになります（中間の `[11, 65, 10]` にコンパレーターが自動配置され、`facing=west`、つまり東側から入力を受け取り西側へ出力します）。
    ```json
    "connects": [
      {
        "src": [10, 65, 10],
        "dst": [12, 65, 10],
        "component": "minecraft:comparator"
      }
    ]
    ```
- 不透明なフルブロックや上面が平らなブロックの上に設置可能です。

## 操作 (Interaction)
- レッドストーンコンパレーターを右クリック（インタラクト）することで、「比較モード」と「減算モード」を切り替えることができます。
- 背面の小さなレッドストーントーチが消灯していれば比較モード、点灯していれば減算モードです。

## 機能・特性
- **信号の比較（比較モード）**: 背面入力が側面入力以上であれば、背面入力と同じ強度の信号を出力します。側面入力の方が強い場合、出力は0になります。
- **信号の減算（減算モード）**: 背面入力から側面入力（左右の強い方）を引いた強度の信号を出力します。
- **コンテナ検知**: 背面にチェスト、ホッパー、ディスペンサーなどのインベントリを持つブロックがある場合、その中身の量に応じた信号強度を出力します。
- **遅延**: 信号の変化に対して2ゲームティック（1レッドストーンティック）の遅延があります。

## 使用方法
- 信号強度の計算、アイテム量の検知、クロック回路、論理ゲートの作成などに使用されます。

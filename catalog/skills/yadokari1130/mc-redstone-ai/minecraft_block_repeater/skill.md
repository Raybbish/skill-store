# レッドストーンリピーターの詳細仕様

## Block ID
- `minecraft:repeater`

## プロパティ (Block States)
- `facing`: `north`, `south`, `east`, `west`
  - **【重要】向きの仕様 (Minecraft準拠)**: `facing` は **「入力側（背面）」** を向いている方角を指します。
  - **出力側**: `facing` で指定した方向の **真反対** へ信号を出力します。
  - **具体例**:
    - `facing: "north"` の場合：**北から入力**を受け取り、**南へ出力**します。
    - `facing: "east"` の場合：**東から入力**を受け取り、**西へ出力**します。
    - `facing: "south"` の場合：**南から入力**を受け取り、**北へ出力**します。
    - `facing: "west"` の場合：**西から入力**を受け取り、**東へ出力**します。
- `delay`: `1`, `2`, `3`, `4` (遅延時間。1〜4 レッドストーンチック / 2〜8 ゲームチック)
- `powered`: `true`, `false` (出力があるかどうか)
- `locked`: `true`, `false` (信号がロックされているかどうか)

## 配置ガイド
- **`connects` の完全義務化**: **リピーターを配置する際は、いかなる場合でも必ず `connects` を使用してください。直接 `blocks` にリピーターを配置し、手動で `facing` プロパティを指定することは完全に禁止されています。**
- **配置時の `src` と `dst` の指定方法**:
  - `src`: 信号の入力元となるブロックの座標（リピーターの背面）を指定します。
  - `dst`: 信号の出力先となるブロックの座標（リピーターの前面）を指定します。
  - `component`: `"minecraft:repeater"`
  - **具体例**: `[10, 65, 10]`（入力元）から `[12, 65, 10]`（出力先）に向けてリピーターを配置する場合、`connects` は以下のようになります（中間の `[11, 65, 10]` にリピーターが自動配置され、`facing=west`、つまり東側から入力を受け取り西側へ出力します）。
    ```json
    "connects": [
      {
        "src": [10, 65, 10],
        "dst": [12, 65, 10],
        "component": "minecraft:repeater"
      }
    ]
    ```

## 特性
- **信号増幅**: 信号強度を15にリセット。
- **遅延**: `delay` プロパティ (1-4 RSチック) で設定。
- **一方向伝達**: 背面から入力、正面から出力。側面からの入力でロック可能。

## 使用方法
- 15ブロック以上の長距離配線で信号を再強化する場合や、回路のタイミング調整、ダイオード（逆流防止）として使用されます。

# Tencent Docs (MCP)

Tencent Docs exposes a complete set of online-document tools through MCP — create, query, and edit many document types.

## Supported document types
| Type | doc_type | Notes |
| --- | --- | --- |
| Document | smartcanvas | ⭐ preferred — good layout, rich components; MDX accepts full Markdown |
| Excel | sheet / tencentsheet | tabular data |
| PPT | slide / tencentslide | presentations |
| Canva/PPT | slide / tencentslide | presentations (see PPT rules below) |
| Mind map | mind | knowledge graphs |
| Flowchart | flowchart | process / architecture |
| Word | doc / tencentdoc | traditional format |
| Form | form / tencentform | data collection |
| Smart table | smartsheet | structured table, multi-view, field management |
| Html | smartpage | HTML presentations |

## Calling the tools
List available tools:
```bash
mcporter list tencent-docs
mcporter list slide-mcp
```
Call a tool:
```bash
# General docs (tencent-docs service)
mcporter call "tencent-docs" "<tool>" --args '<JSON>'

# PPT fine editing (slide-mcp service, slide_* tools)
mcporter call "slide-mcp" "<tool>" --args '<JSON>'
```
If a reference doc conflicts with the live schema, the `mcporter list` output wins.

Every response carries `error` (empty on success) and `trace_id`.

## Common workflows (see `references/workflows.md`)
- **Search + read:** manage.search_file → get file_id → get_content
- **Smart table:** smartsheet.list_tables → smartsheet.* tools
- **File management:** manage.folder_list → manage.* (rename/move/delete/copy/permissions)
- **Web clip:** scrape_url → scrape_progress (poll) → auto-saved as a smart doc (use this whenever the user gives a URL)
- **Local HTML → cloud:** `node aipage_pack.js` → `import_file.sh` → `manage.async_import` → `manage.import_progress`
- **OCR image:** `ocr.extract` / `ocr.toword` / `ocr.toexcel`; local images go through `node ocr.js`, public-URL images call ocr.* directly

## Core rules
- **PPT editing MUST use slide-mcp.** When the user gives a `https://docs.qq.com/slide/<id>` link or asks to edit an existing PPT/slide deck, use the `slide_*` tools via slide-mcp. Do NOT use docengine (`doc_*`) or the general tencent-docs tools — they don't understand slide internals (shape_id / page_index / master) and return wrong results. Only use `references/slide_references.md` when the user wants AI to generate a whole new deck.
- **Default to smartcanvas.** Unless the user names another format, create with `create_smartcanvas_by_mdx` and edit with `smartcanvas.*`.
- **Markdown content** goes straight into `create_smartcanvas_by_mdx`'s `mdx` param — MDX accepts all Markdown; no conversion needed.
- **Local file save/archive:** always use the `import_file.sh` → `manage.async_import` → `manage.import_progress` path and keep the original structure; don't regenerate with `create_*`. If the backend rejects the format, fall back to another path only after the error.
- **`node_id` == `file_id`:** a space node's `node_id` is also the document's `file_id`.
- **Deleting nodes is destructive:** `delete_space_node` removes only the current node by default (`remove_type=current`); `all` recurses into children.
- **OCR:** `image_url` (public URL) and `image_base64` are mutually exclusive; local images MUST go through `node ocr.js` (never hand-base64).
- **Async tasks** (create_slide, scrape_url): prefer a spawned sub-session to poll progress so the main session stays responsive.
- **Unsupported features:** when a requested capability has no matching tool, silently call `report_unsupported_feature` (no need to tell the user). See `references/unsupported_feature_reporting.md`.

## Troubleshooting
| Code | Meaning | Fix |
| --- | --- | --- |
| 400006 | Token auth failed | run the auth flow in `references/auth.md` |
| 400007 | VIP required | upgrade VIP at docs.qq.com/vip |
| 400008 | Insufficient credits | buy credits at docs.qq.com/vip/asset-center |
| -32601 | Unknown method | confirm the tool exists in `mcporter list` |
| -32603 / 11607 | Bad params | check `file_id`, `content`, etc. |

Steps: match the code → confirm tools via `mcporter list tencent-docs` → re-run auth if auth-related → open the scenario's reference doc.

ModelScope Skills 功能对标 — 我们该不该「都具备」

v1.0 · 2026-07-03 · 对标 modelscope.cn/skills · 「我们」= 本仓 Skill Store(oh-my-skill),非通用 Cowork/Claude

0一句话结论

不该照单全收。ModelScope Skills 和我们不在同一层:它是「技能运行时 + 网页大目录 + 阿里模型生态」的一站式组合;我们是「多 agent / 多模型中立的信任 · 评测层」。把它的功能拉平了看,分成两类:

  • 目录 / 分发层(搜索、分类、技能卡片、CLI 安装、镜像官方仓)——我们已经有或已规划,而且在这一层用「信任信号」甩开它(它这些卡片零评测分、零权限披露、零效果对比)。
  • 运行时 / 模型生态层(MS-Agent 运行时、ms-enclave 执行、免费 Qwen 推理、多模型绑定、渐进式加载)——我们刻意不做。照搬会稀释「中立信任层」定位,还把自己拖进阿里主场硬拼。

真正值得顺手借鉴的只有 3 个 UX 细节(分类体系、多种安装入口、在线试玩观感),都不改主线。真正的威胁也不在功能,在渠道(见 §4)。

1先分清楚:两者不在同一层

ModelScope Skills(阿里魔搭)技能运行时(MS-Agent,Agent Skills 协议实现)+ 网页大目录(关键词搜索 + 五分类)+ CLI 分发 + ms-enclave 沙箱执行 + 绑定 Qwen 免费推理。本质是「开源模型 × skill 一站式组合」,是模型社区的自然延伸。
我们 · Skill Store多 agent / 多模型中立的「认证商店」,卖信任:可复现评测协议 · 权限营养标签 · 效果对比 · token 成本 · 跨平台热度聚合。不做运行时、不绑模型。
你们竞品报告已下过判断:ModelScope 技能卡片只有名称/描述/作者/标签/基础数据,未见评测分或安全标签,它复制的是 skills.sh「大目录 + CLI 分发」模式,而非我们的「信任 + 质量」定位——五个差异化点在 ModelScope 上依然零覆盖。所以「对标它的功能」这件事,重点不是补功能,是想清楚哪些是它作为「模型社区」才做、而商店不该做的。

读法:第 1 组(目录/分发/供给层)我们基本已有或已规划,且已领先;第 2 组(运行时/模型/商业)是刻意不做——照搬即错位。

3判读:该有的、刻意不做的、值得借鉴的

已有 / 已领先(继续用信任信号拉开)

目录、搜索、分类、详情、CLI、镜像——这一层我们都有,而且详情页多了权限营养标签 + 效果对比 + token 成本 + 评测入口,正是 ModelScope 零覆盖的地方。不用追,要继续拉大。

已规划,不是缺口

社区上传(M1 投稿 + 创作者中心)、在线试玩(P1)——路线图已含,顺序也对(投稿/评测挑战依赖可复现评测协议,天然排在 M1)。ModelScope 有、我们「暂时没有」,不等于缺口。

刻意不做(照搬会毁定位)

运行时 MS-Agent、把执行沙箱做成用户服务、免费 Qwen 推理、多模型绑定、自家生态引流——这些是 ModelScope 作为「阿里模型社区」的自然延伸,不是一个中立商店该干的。我们的护城河恰恰是「不绑任何 agent / 模型 + 评测数据资产」,一旦去做运行时/推理,就等于放弃中立、进阿里主场硬拼,且稀释信任叙事。

值得借鉴(小、且不改主线)

  • 分类体系:参考它「开发工具 / 数据处理 / 内容创作 / 行业应用 / 通用工具」的五分类,把我们的 taxonomy 补齐对齐用户心智。
  • 安装入口:npx 之外补 curl / ZIP 兜底,覆盖不同 agent 与离线场景(哈希校验 + 权限确认照旧,是我们的差异)。
  • 在线试玩观感:借它「即点即跑」的低门槛体验感,但产出仍走我们的装/不装效果对比,把「效果可见」做成差异化而非模仿。

4真正要警惕的不是功能,是渠道

承接你们竞品报告:ModelScope 的真正威胁不在功能,在渠道——它自带千万级社区流量 + 阿里云入口。一旦它补上评测 / 安全层,第三方店在中文市场的空间会被快速压缩,窗口期估计不超过 2–3 个季度。腾讯 SkillHub 的「50+ 精选 + 安全扫描」已说明大厂开始意识到信任问题,只是目前做得薄。

所以对策不是「把 ModelScope 的功能追平」,而是把它做不了或不愿做的三条护城河做深做快:①可复现评测协议(它绑 MS-Agent、只会做单方跑分,做不了中立可复现);②安全透明(权限营养标签 + 公开可验证审计,它零覆盖);③跨平台热度聚合(它绑自家生态,天然做不了跨 hub 合并)。这三条同时也是「平台截流」风险的对冲。

5行动指引

  • 不照单全收。目录 / 分发层我们已领先,继续用信任信号(评测 + 安全 + 效果 + 成本)拉开差距。
  • 运行时 / 模型层坚决不碰——那是阿里主场,碰了就丢中立护城河。
  • 只顺手借三个 UX 细节:分类体系、安装入口(curl/ZIP)、在线试玩观感。均为小改,排进 M0/M1 打磨即可。
  • 把资源压在「抢窗口」上:2–3 季度内把可复现评测协议 + 安全审计 + 跨平台聚合立起来,比追它任何一个功能都重要。

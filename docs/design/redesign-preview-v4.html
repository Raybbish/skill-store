oh-my-skill 认证流程

带认证图标的 skill,上架前都走完了下面这条可公开复核的链路。所有审计报告随 catalog 仓公开,变更走 PR、每条记录带 commit 溯源。

采集
从官方精选仓与头部榜单收录,记录上游 commit。
去重 · 内容哈希
content_hash 去重,并作为安装时的校验锚点。
L1 静态签名
YARA + 正则,拦已知恶意模式(密钥外传、危险命令)。
L2 脚本数据流
追踪脚本的读取→外传路径,产出风险五因子。
L3 意图审查
模型审查 SKILL.md 指令意图,抓提示注入,双模型交叉。
人工复核
含网络外联的一律进人工队列放行,不给绿灯免检。
上架 · 可验证
货架显示状态;琥珀色图标 = 待复核,不是通过。
权限营养标签 · 五因子逐项披露

脚本执行 附带可执行脚本
文件读写 访问范围

# ADR 0002 — skill / 发布者图标与 logo 的 IP 策略
- 日期:2026-07-03
- 状态:已定方案,**推迟到产品成型最后阶段**再落地(不进 M0/M1 核心)

## 背景
冷启动需要图标。选项:等开发者上传,还是直接用开发者 logo(如 Anthropic)?后者有侵权风险。

## 决策(分级,风险从低到高)
1. 默认**中性 monogram**(几何 / 字母自动生成)——当前前端正是无图标状态,天然落在这档。
2. 可选拉 **GitHub org/repo 头像**并注明来源、留下架入口。
3. 开发者**认领 / 上传**自己的图标来覆盖(顺带做成 M1 发布者认领入口)。

## 约束(红线)
- **Apache-2.0 §6 不授予商标许可**:"按许可证镜像 skill 内容" ≠ "可用其 logo"。
- 认证 ✓ 徽章叠加他方 logo 有**虚假背书**风险 → 认证措辞写明「oh-my-skill 认证」、发布者身份与平台认证视觉分离、加不隶属声明。
- DMCA 流程并入「商标 / logo 移除请求」。

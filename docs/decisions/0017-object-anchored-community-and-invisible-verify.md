# ADR 0017 — 社区对象锚定 + 隐形验证安装
- 日期:2026-07-07
- 状态:已采纳
- 详细设计:[社区层设计 v2](../planning/社区层设计v2-对象锚定与隐形验证.html)(取代《社区层设计与需求收敛》,旧稿移 `docs/_archive/`)

## 背景
两个前提变了:

1. **定位重述**:不以「卖信任」为主叙事——扫描已下架待重设计(ADR 0011/0012),不成熟阶段卖不了信任。主打**活人感**(真实的人/产物/更新出现在货架上)。
2. **用户面拓宽**:目标用户包含大量不会用 GitHub、不敢碰终端的人。原验证设想(CLI login + GitHub device flow)对这批人不可用。

同时,现有 `/community` 原型是**论坛结构**(四板块 + demo threads):零用户期上线空板块+演示数据,是活人感的反面,与「真诚」原则直接冲突。

## 决策

### 1. 社区结构 = 豆瓣(条目中心),不是论坛
四个板块重构为**四种内容类型**,全部锚在对象(skill 详情页/作者页/包页)上:短评(M1)、求助 Q&A 绑版本(M1)、开发者说(M1)、用法笔记(M2)、评测挑战(M3,评测线真实跑通为前置)。「公告&复盘」拆出社区,做成商店官方 blog。

每种类型必须通过「**零回复自价值**」测试(零互动时对发帖人自己有价值),否则不上。

`/community` 聚合页**最后建**:密度门槛周新帖 > 20 才开;此前导航不出现社区入口。demo threads 不上线。

### 2. 「已验证安装才可评」= 隐形渠道回执(App Store 模式)
密码学上无法证明安装(文件公开、安装免费且本地),目标改为:服务端留痕 + 提高刷评成本 + 措辞诚实。验证藏在安装动作里,用户永远不见「请验证」步骤:

- **主路径**:网页「安装」= 下载 `.skill` → 拖进 Claude。下载在服务端,天然回执。
- **次路径**:「复制安装命令」内嵌短 token(`add pptx --t 8f3k`),CLI 装完回传,绑到网页会话。免 login/device flow。
- **兜底**:`verify` 子命令(本地复算哈希 + 短码)覆盖手动/第三方渠道安装。

### 3. 账号 = 邮箱验证码 + 延迟注册
浏览/下载不登录(回执挂匿名会话);按「写评价」时才要 email OTP,登录后回执并入账号。GitHub OAuth 降为开发者可选项。

### 4. 反刷 = 权重,不是门槛
冷却 24h、设备/IP 限频、进榜评分只算「有回执+有账号龄」、认领作者不可自评。诚实认账:邮箱 sybil 成本低于 GitHub,当前规模够用,升级留 P3。

### 5. 徽章措辞
「**从本店安装**」——只 claim 获取渠道,不 claim 使用深度,不做安全背书(沿用全站「不说保证安全」红线)。

## 后果 / 约束
- **工程排序**:验证系统是「.skill 下载体验」的副产品。先把下载→拖入 Claude 修丝滑;回执覆盖率是徽章的天花板。
- **副产品**:回执匿名聚合 = 自有装机量(可先于账号层,machine-id 匿名计数、首跑明示、可关),发现排序摆脱 skills.sh 依赖。
- **数据**:`install_receipts` / `reviews`(绑 `content_hash`,UNIQUE(user,skill))+ M0 预留 threads/comments schema 原样够用。评论/评分是「第一条不可重建的关系型用户数据」→ 命中 ADR 0008 判据,与 M1×P2 Postgres 同批落。
- **对 ADR 0001 的修订**:保留其内核(互动挂在资产上、评价需已验证安装);「信任原生」叙事改述为「对象原生 + 活人感」;其 M1「社区最小切片」的实现即本 ADR 的 M1 三类型。
- **移除项**:`packages/web` 的 `/community` 四板块页与 `lib/community.ts` demo 数据不随 M1 上线(代码可留,导航摘除)。

## 补充裁决(2026-07-08):verify 升主通道 + 徽章语义分档
用户指出:早期用户大多**已经装过**这些 skill(skills.sh / 手动 / 插件渠道),为验证身份重装一次不可接受——路径③(verify)对早期人群不是兜底,是**主通道**。随之收紧语义红线:verify 只能证明「本机确有此物」,证明不了来源,故徽章分两档——download/cli 回执 =「**从本店安装**」,verify 回执 =「**已验证本机安装**」,不得混用。落地:CLI `verify <id>`(找本地副本→复算哈希→与货架比对→回执记**实际持有**的哈希,评价侧据此显示「评于版本」)+ `verify --all`(扫描本地全部已装,逐个比对——顺带充当 outdated 检查,单人价值自足);详情页安装区第四小节「已经装过?」给可复制的 verify 命令(带 --t token 绑 web 会话)。

## 执行(2026-07-08)
用户裁决「全扫三处」,超出本 ADR 最小的「仅摘导航、代码可留」—— demo 层整套删除:
- 删除 `/community` 路由(page + client)、`lib/community.ts`(demo threads + 假发布者指标)、`components/ThreadRow.tsx`、详情页 `SkillCommunity` 块;`lib/community.ts` 重写为 `lib/publishers.ts`(仅 catalog 派生的真实数据:作品集 / 累计安装)。
- 发布者页只留真实字段;移除假的求助响应·评测复现·bio·加入日期,以及「已认证发布者 ✓」徽章(后者系 ADR 0011 认证下架的残留)。
- 详情页 `★ 社区精选`(真实 `curatedBy`)保留;`globals.css` 孤儿样式暂留。
- 验证:web `tsc --noEmit` 绿、全仓零残留引用;`web:build` 回归留本机。

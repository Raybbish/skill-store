# ADR 0001 — 信任原生社区(非 TapTap 式社区优先)
- 日期:2026-07-03
- 状态:已采纳

## 背景
需求问答一度倾向做 TapTap 式大社区;但 PRD 主张「发现是红海,卖的是信任」,社区列 P1。两条路会长成不同产品。

## 决策
主线不变(可复现评测 + 权限营养标签 + 安全审计)。社区做成**信任的放大器**,所有互动挂在信任资产上:
- 评价 = 已验证安装才可评(杜绝刷评)
- 求助 = 绑定 skill + 版本,沉淀为使用知识库
- 评测挑战 = 用户复现 / 质疑货架分(别家零覆盖)
- 晒用法 = 效果对比的 UGC 版

## 后果 / 路线图
- M0 不动:评价位=审计摘要占位;DB 预留 `threads/comments` schema(关联 `skill_id + version + verified_install`)。
- M1:社区最小切片 + 账号层(Supabase Auth,GitHub + 邮箱)+ 可复现评测协议一起上。
- M2:完整论坛 / 晒用法动态流 / 创作者看板 / i18n 全量。

# ADR 0034 — 首页与榜单对调:店况首页 + /browse 目录检索

- 日期:2026-07-17
- 状态:已采纳,代码落地待合(分支 `feat/home-browse-swap`);设计稿与拍板记录见 Desktop《skill-store-首页与榜单对调-设计稿.html》(二稿,含 taste 自审)
- 关联:ADR 0007(store.search 缝,不动)、ADR 0017(「活人感」定位)、ADR 0022(双路由,本条新增 /browse 一对)、7629a006(PackShelf 手动横滑,首页复用)

## 背景

卖点是「活人感」(ADR 0017),但门面给了目录检索页:大 hero + 16 分类 + 分面 + 全量列表,一年到头长一个样;真正天天变的榜单(按日新上架 + 热门)藏在二级 tab。用户裁定对调,并加一条硬约束:首屏信息密度不降(生产力工具,刷新一屏的信息量不能低)——不是把稀疏的旧榜单页原样搬上来。

## 决策

**路由**:`/` = 店况首页(原榜单进化);`/browse/` = 目录检索真身(原首页整体迁入,旧壳方向反转);`/charts/` = 薄壳跳 `/`。en 镜像同理,新增 `/en/browse/`。旧 `/` 检索深链(?q=&cat=&tag=&repo=&pub=)由首页客户端转发到 /browse/ 同参保活(静态导出,与旧 /browse 壳同模式)。

**店况首页**(密度手段三条):砍 hero 成一行事实条(收录 N · 今日 +a · 本周 +b + 搜索框,搜索只是入口、提交跳 /browse/?q=;今日 +0 时整项不显示,不写「+0」也不编数);新上架行压成 SkillRow `variant="compact"` 两行(砍场景词行与「获取」钮,~64px/条);热门变右栏单行榜 TOP 20(~34px/条)。PackShelf 原样复用整行放事实条下。移动端单栏,双 tab(文字无 emoji)。

**追记(2026-07-18,dev 目检裁定)**:首页新上架只展示**最新一日**,不铺「昨天/更早」流水(今天空档顺延最近一天,无空窗;今日计数仍按真实今天算)。全量时间线走「全部新上架 › /browse/?sort=new」。

**有意重复(拍板)**:右栏热门与 /browse/ 默认态同数据同序 —— 门面摆畅销切片是零售常态,不是待修问题;真差异化(动态 feed / 轮换推荐)留作后手。

**浏览页**:能力不变(搜索/分类/分面/排序/分页),hero 降级小标题,货架撤下(包只在首页与 /pack/);分类 chips 全量留在此页,首页不设分类捷径。

**退役**:评测榜置灰 tab(头版不挂期货,上线时走动态页宣布);charts.* 词典键迁 home.*;组标题「今天 7月17日」改空格连接(中点每行至多一个,taste 自审)。

## 影响与验收

- 内链改点:SkillRow 场景词、分类页「看全部/← 全部 skill」、收录页「已收录 ›」、详情页场景词,统一改指 /browse/;埋点 trackClick rank/pos 口径不变。
- SEO:/ 语义换口径、/browse/ 为新收录 URL,短期排名会晃;langAlternates 三对补齐。绑域名前是最便宜的晃动窗口。
- 验收清单(设计稿 05):五参深链转发不丢参;/charts/ 落回 /;en 四路由通;今日空时顺延昨日无空窗;移动端双 tab 可切;货架横滑与 ‹› 箭头行为不变;browse 无货架。
- 沙箱注记:app/charts/ChartsView.tsx、ChartsClient.tsx 因挂载盘 unlink 受限只能置空 stub,合并前需终端 `git rm`。
